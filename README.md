CSS Flexbox & Animation Projects
About the Project
This repository contains my practical assignment for CSS Flexbox & Animation, organised as part of the Upskill by Genesys learning programme.

The goal of this project is to practise CSS Flexbox for creating flexible layouts and CSS animations for adding movement to webpages. It also helps me improve my understanding of HTML, CSS, responsive design, and GitHub.

Projects Included
1. Design a Set of Colorful Boxes
Category: Flexbox Workshop

A webpage displaying colourful boxes arranged using CSS Flexbox.

Concepts practised:

display: flex
justify-content
align-items
flex-wrap
gap
2. Design a Pricing Plans Layout Page
Category: Flexbox Lab

A pricing page displaying three plans: Starter, Professional, and Premium.

Concepts practised:

Flexbox layout and alignment
Flexible card sizing
Spacing and visual styling
Responsive layouts using media queries
3. Build an Animated Ferris Wheel
Category: Animation Workshop

A Ferris wheel illustration with rotating spokes and cabins.

Concepts practised:

CSS @keyframes
transform: rotate()
Animation duration and timing
Infinite animations
CSS positioning
4. Build a Moon Orbit
Category: Animation Lab

An animated illustration showing a moon revolving around a stationary planet.

Concepts practised:

CSS animations and keyframes
Relative and absolute positioning
CSS transforms
Animation speed and direction
Circular orbit layouts
